## DirSizes 0.4.0

### Full Disk Access at launch

Without Full Disk Access, macOS asks separately about every protected folder a scan reaches
(Desktop, Documents, Music, Photos, other apps' data). DirSizes now asks for Full Disk Access
when it starts instead: **Open System Settings** goes straight to the right page, and the
scan starts by itself as soon as DirSizes is turned on. **Not Now** scans without it, and a
banner on the start screen offers to set it up later.
