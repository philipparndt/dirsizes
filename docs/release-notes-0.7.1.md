## DirSizes 0.7.1

### Photos library inside the iCloud chart

The iCloud chart now shows your Photos library on this Mac file by file, as a folder next to
iCloud Drive in iCloud's color for Photos: click into it, reveal items in Finder or add them
to the Collector. What iCloud stores for Photos beyond it is a see-through "Photos only in
iCloud" slice. Before, the library was a single slice that opened in a separate scan.

Reading the library needs Full Disk Access (Photos libraries are protected); without it, the
Photos row says so.
